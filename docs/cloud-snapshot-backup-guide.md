# 阿里云、腾讯云国际版快照与备份怎么做

很多人做完阿里云账号购买或腾讯云账号购买，机器一开就上线，备份却一直排在"以后再说"。可云服务器不会自动替你备份数据：误删文件、升级失败、被入侵或者前面讲过的欠费释放，都可能让数据一夜消失。云盘快照是成本最低的一道保险。

本文整理两家国际版官方文档里关于快照的规则：原理是什么、怎么设自动策略、保留多久、怎么计费，以及恢复前要核对什么。规则会调整，文中附了官方出处，请以官方最新说明为准。

## 先记住一件事：不会自动备份

阿里云 ECS 官方文档明确写明，ECS 实例**不会自动备份**云盘数据，建议创建实例后按周期创建快照（见 [Snapshots overview](https://www.alibabacloud.com/help/en/ecs/user-guide/snapshots-overview)）。腾讯云 CBS 的快照同样需要你自己创建，或者配置定时快照策略。两家的快照都是针对**云盘**，不是整机拷贝；阿里云的本地盘、临时盘不支持快照。

## 两家快照的原理对比

| 对比项 | 阿里云国际版（ECS 云盘快照） | 腾讯云国际版（CBS 云硬盘快照） |
| :--- | :--- | :--- |
| 备份方式 | 首份标准快照为全量，之后为增量，只备份变化的数据块 | 首份为全量，之后为增量，只保存相对上一份有变化的数据 |
| 自动策略 | 自动快照策略：选星期几、整点时间，一天最多 24 个时间点 | 定时快照策略：可精确到每小时或每天 |
| 保留期 | 1 到 65,536 天，或永久；自动策略里另有保留数量上限设置 | 定时快照可设 1 到 30 天，或永久；手动快照默认永久保留 |
| 跨地域 | 支持把标准快照复制到另一个地域，产生复制流量费 | 支持跨地域复制，产生跨地域流量费 |
| 其他 | 可锁定快照防误删；可用系统盘快照制作自定义镜像 | 自定义镜像的数据存放在快照服务里，保留镜像也占用快照容量 |

腾讯云的原理说明见 [Snapshot Principles](https://www.tencentcloud.com/document/product/362/31640)，定时快照说明见 [Scheduled Snapshots](https://www.tencentcloud.com/document/product/362/35238)。

## 阿里云：设置自动快照策略

官方入口在 ECS 控制台的"自动快照策略"页面，详见 [Create an automatic snapshot policy](https://www.alibabacloud.com/help/en/ecs/user-guide/create-an-automatic-snapshot-policy)。要点如下：

1. 先选对**地域**，策略按地域生效，每个地域每个账号最多可保留 100 个自动快照策略。
2. 选择执行频率（周一到周日）和执行时间（按东八区、精确到小时），快照会在所选整点后一小时内创建。
3. 创建快照可能带来一次毫秒级的磁盘 I/O 波动，官方建议避开业务高峰。
4. 设置保留期：可以永久保留，也可以自定义天数，到期自动删除。官方提示，修改保留期只影响之后新建的快照，已有快照不变。
5. 把策略应用到系统盘和数据盘。如果磁盘数据量大、一份快照耗时超过两个时间点的间隔，系统会跳过下一个时间点。
6. 注意"随磁盘释放"这一选项：开启后，磁盘被释放时未到期的自动快照也会一并删除。想把快照当成"实例没了还能救回来"的保险，就要想清楚这个选项。

## 腾讯云：设置定时快照

腾讯云官方给的参考做法是：核心业务每天一次，保留 7 到 30 天；非核心业务每周一次，保留 7 天；归档和测试快照手动创建，用完即删。每个账号每个地域最多设置 30 个定时快照策略，一个策略最多关联 200 块云盘。

手动创建快照时有两个官方提醒：快照只能保存**已经写入磁盘**的数据，内存缓冲区里的数据不在其中。所以数据库类业务建议先加读锁再做快照，系统层面可以先执行 `sync` 把缓冲数据写盘，详见 [Creating Snapshot](https://www.tencentcloud.com/document/product/362/5755)。

## 快照怎么计费

- **阿里云**：开通快照服务免费，创建快照后才开始计费，按各地域标准快照的总大小和存储时长收费；做跨地域复制还会另收复制流量费和目标地域的存储费。归档快照最短保留 60 天，提前删除要补收费用。具体单价以 ECS 产品页的定价标签为准。
- **腾讯云**：按各地域快照的总存储容量计费，每小时一个计费周期，各地域分开算；跨地域复制另收流量费。价格表见 [Price Overview](https://www.tencentcloud.com/document/product/362/2413)。

两家的共同点是：只要快照不删，存储费就一直在走。所以自动策略要配上合理的保留期，别设成永久后就忘了。账单里如果出现陌生的快照项目，可以对照 [账单与用量怎么看](cloud-international-billing-usage-guide.md) 逐项排查。

## 一套够用的备份习惯

1. **先分级**：数据库、用户上传文件所在的盘每天备份；只放程序、随时可重装的盘每周备份。
2. **大改动前手动做一份**：改配置、升级系统、迁移前先手动快照，确认创建完成再动手。
3. **重要数据做跨地域副本**：快照默认和云盘在同一地域，想防范地域级故障，就复制一份到别的地域，地域选择可参考 [地域怎么选](cloud-region-selection-guide.md)。
4. **别只靠快照**：阿里云官方说明已创建的快照不能直接下载或导出，只能先做成自定义镜像再导出。需要离线保存的数据，还是要另外做文件级备份。
5. **保证账户有余额**：快照服务和账户状态挂钩，欠费会影响它，腾讯云文档也写明手动快照"只要账户余额充足"就永久保留。余额预警设置见 [欠费停机怎么办](cloud-overdue-payment-suspension-guide.md)。
6. **恢复演练一次**：新建一块云盘或一台测试实例，从快照恢复一次，确认数据能用。阿里云官方也提醒，从快照回滚或创建的磁盘，未加载的数据首次访问时读延迟会偏高。

## 常见问题

**快照和镜像有什么区别？**
快照是云盘某一时刻的数据副本，主要用来恢复和回滚；镜像包含系统和环境，用来批量创建新实例。镜像可以由系统盘快照制作。

**快照会占用多少空间？**
增量快照只保存变化的数据，所以第一份最大、后面的相对小，但实际容量取决于你的数据变化量，以控制台和账单显示为准。

**换了账号，快照还能用吗？**
快照属于创建它的账号和地域。阿里云支持把快照共享给其他阿里云账号，具体权限和限制以官方文档为准；跨站点（中国站与国际站）能否共享，请先查官方说明，不要想当然。
