# 阿里云、腾讯云国际版欠费停机怎么办

不少人做完阿里云账号购买或腾讯云账号购买，机器跑得好好的，某天突然连不上，登录控制台才发现是余额用完了。欠费本身不可怕，可怕的是不知道平台给了多长时间，拖过保留期后磁盘和数据被释放，再也找不回来。

本文把两家国际版官方文档里关于欠费、停机、保留和释放的规则整理成一张时间线，再给出恢复步骤和预防办法。规则会调整，文中都附了官方出处，请以官方最新说明为准。

## 先分清两种计费方式

| 计费方式 | 什么时候会出问题 | 典型表现 |
| :--- | :--- | :--- |
| 包年包月（Subscription） | 到期未续费 | 到期后进入停服、回收流程 |
| 按量付费（Pay-as-you-go） | 账户余额不足以支付账单 | 欠费后经过宽限期停机 |

包年包月的费用已经预付，账户欠费一般不影响有效期内的使用，但会挡住升级、续费、新购这类会产生费用的操作；如果包年包月实例上挂着按量计费的公网带宽或流量，这部分按量组件会受欠费影响。按量付费资源则直接受余额影响，是最容易出事的地方。

## 阿里云国际版：按量付费 ECS 的时间线

根据官方文档 [Overdue payments（ECS）](https://www.alibabacloud.com/help/en/ecs/overdue-payments)：

| 时间点 | 发生什么 |
| :--- | :--- |
| 结算日 T 扣款失败 | 视为欠费。服务继续运行，但不能新购资源、升级配置或开启自动续费 |
| T+7、T+14 | 系统再次尝试扣款 |
| T+15 三次扣款都失败 | 实例停机、停止计费，无法远程连接，网站无法访问 |
| 停机后 15 天内 | 计算资源、云盘及数据、固定公网 IP 仍保留，但不提供服务 |
| 停机超过 15 天 | 开始释放按量付费的计算资源、云盘和公网 IP，数据无法恢复 |

几个容易忽略的细节：

- **节省停机模式**的实例停机后会回收 vCPU 和内存，欠费时可能无法启动。
- 欠费期间自动快照停止，也不能手动创建快照，所以想在欠费后再「补个备份」通常来不及。
- EIP、负载均衡、OSS 等产品各有独立规则。按官方 [欠费处理说明](https://help.aliyun.com/en/user-center/timely-handling-of-arrears)，CLB / NLB 欠费后的保留期是 7 天，比 ECS 短，有负载均衡的业务要格外注意。

## 腾讯云国际版：按量付费 CVM 的时间线

根据官方文档 [Overdue Payments（CVM）](https://intl.cloud.tencent.com/document/product/213/2181) 和 [Terminating/Returning an Instance](https://intl.cloud.tencent.com/document/product/213/4930)：

| 时间点 | 发生什么 |
| :--- | :--- |
| 账户余额变为负数 | 实例继续可用并继续计费，最长 2 小时 |
| 欠费满 2 小时 | 实例自动关机、停止计费，移入回收站 |
| 进入回收站后 15 天内 | 把余额充到大于 0 后可以重新启动实例 |
| 超过 15 天 | 自动释放 CPU、内存、普通公网 IP、非弹性云硬盘及数据，无法恢复 |

腾讯云的宽限期只有 **2 小时**，比阿里云短得多。也就是说，按量付费的腾讯云机器几乎没有「欠费还能先跑着」的缓冲，余额见底基本就等于停机。另外，弹性云硬盘和 EIP 的欠费规则在单独的文档里说明，挂了这类资源要分别查看。

包年包月 CVM 到期未续费时，官方说明是到期后约 48 小时内停服隔离（不关机、数据保留）并移入回收站，回收站内保留 15 天，期间可以续费恢复。

## 欠费后怎么恢复

**阿里云国际版**

1. 登录控制台，进入 Expenses and Costs（费用与成本），在账户总览顶部的欠费提示里点 Pay Now，结清欠费账单。
2. 结清后实例通常会自动恢复；没有恢复的，在 ECS 控制台手动启动。
3. 启动后检查网站、数据库和定时任务是否正常，确认自动快照策略已经恢复。

**腾讯云国际版**

1. 先给账户充值，让余额回到大于 0。
2. 在 CVM 控制台或回收站中找到实例，执行恢复或启动。注意官方说明：账户仍欠费时，回收站里的按量实例无法执行恢复，必须先充值或续费。
3. 恢复后检查公网 IP 是否变化（普通公网 IP 在释放前一般保留，但已释放的无法找回），以及业务是否正常。

如果你的账号是通过渠道办理的，没有绑定自己的国际信用卡，充值路径就是渠道充值。例如在 [云大仙国际云充值](https://www.yundaxian.com/recharge) 按账号 ID 用 USDT 充值，30 USDT 起充，到账后再按上面的步骤恢复。欠费恢复讲究时间，尤其是腾讯云只有 2 小时宽限，建议平时就熟悉充值流程，不要等停机了才第一次操作。

## 怎样提前避免欠费停机

1. **设置余额预警**：两家控制台都支持在可用余额低于阈值时发送通知。把阈值设成至少一周的消耗，而不是一天。
2. **通知渠道要有人看**：预警邮件和短信发到你常用、能及时看到的邮箱和手机号上。账号刚接手时就要换绑，具体做法见 [国际云账号风控与防封清单](cloud-account-risk-control.md)。
3. **估算月消耗**：在账单页看最近一个月的日均消费，按量付费的公网流量最容易突然变大。阿里云用户可以先开通 CDT，把流量费压下来，见 [阿里云国际版 CDT 每月 220GB 免费流量](aliyun-international-cdt-free-traffic.md)。
4. **长期稳定的机器改成包年包月**：业务稳定后转为包年包月并开启自动续费（前提是余额充足），可以避开按量付费的短宽限期。
5. **定期快照或镜像**：重要数据定期做快照，并保证账户正常时快照在持续生成。欠费期间是无法补做快照的。
6. **财务权限分开**：让负责付款的同事用单独的子用户查看账单和余额，而不是共享主账号，见 [阿里云 RAM、腾讯云 CAM 子用户怎么设](ram-cam-subuser-permission-guide.md)。

## 常见问题

**欠费会不会导致账号被封？**
欠费触发的是停机和资源释放流程，和违规导致的账号风控是两回事。结清欠费后账号即可正常使用。但长期欠费不处理，资源会按上面的时间线被释放。

**资源被释放后还能找回吗？**
按两家官方说明，释放后的数据无法恢复。唯一的办法是事前做好快照、镜像或异地备份。

**我只想停用，不想再付费怎么办？**
主动释放不再需要的按量实例和云盘，比任由欠费更干净。欠费状态下余额是负数，之后再充值时会先抵扣欠款。

## 账号与充值从哪里来

想让欠费恢复和日常续费都可控，前提是有一个真正属于自己、能按账号 ID 充值的独立主账号。没有合适国际信用卡的团队，可以通过 [云大仙](https://www.yundaxian.com/) 办理 [阿里云账号购买与阿里云代开](https://www.yundaxian.com/open/aliyun) 或 [腾讯云账号购买与腾讯云代开](https://www.yundaxian.com/open/tencent)，已有账号可在 [国际云充值](https://www.yundaxian.com/recharge) 用 USDT 续费。

## 一句话总结

阿里云按量付费欠费后大约 15 天才停机、停机后再保留 15 天；腾讯云按量付费欠费 2 小时就关机、回收站保留 15 天。设好余额预警、提前充值、定期快照，比任何事后补救都可靠。
